# 多语言与 UI/UX 验证记录

验证日期：2026-10-22。基于 Expo SDK 56、React Native 0.85.3。

## 已验证

- `npm test`：7 项通过。覆盖四种语言各 366 个不重复问题、12 个阶段、48 条开场提示；全部 UI 键与占位符；语言地区匹配；ID 与提示映射稳定；旧 v1 数据兼容；保存与重置顺序；保存失败后恢复。
- `npm run typecheck`：通过。
- `npx expo config --type public`：通过，四种语言配置被识别。
- `npx expo export --platform all`：通过，生成 Web JavaScript 及 Android/iOS Hermes 字节码。
- 浏览器实测：320×568、390×844、768×1024 视口。查看了英文欢迎页及手机/平板卡片、日文卡片、韩文卡片和历史、中文空状态。
- 英文开始旅程、抽题、显示提示、收藏成功；切换日文后仍是同一题，收藏状态保持。
- 从日文旅程弹窗选择第 12 个主题后，主题能自动滚入可见区域，并可抽取对应月份的问题。
- 切换韩文并刷新后，所选语言、主题、历史、收藏保持；历史中的两个不同主题问题均显示韩文。
- 320px 韩文主界面与 768px 英文主界面未检测到页面横向溢出；320px 英文和韩文抽样内容未检测到文字容器横向裁切。
- 英文重置提示可取消；确认重置本次预览中创建的测试旅程后回到欢迎页，刷新仍保持 English。随后切回中文，验证空收藏提示及默认主题。
- 浏览器中的语言选项、主题、收藏、提示和列表页签具有可读的选择/展开状态。

## 范围与限制

- 未安装到 Android/iOS 真机，未生成 APK/IPA，也未发布商店版本。字节码导出通过不代表原生运行体验已验证。
- 系统大字体已通过布局实现适配，但尚未进行真机放大字体、VoiceOver/TalkBack、系统逐应用语言和触觉反馈测试。
- 所有翻译已检查数量、顺序与唯一性，并抽样运行查看；尚未经母语编辑逐条审校。
- 原有数据格式和存储键保持不变；语言设置使用独立存储键。
- 首轮沙箱内 Hermes 导出因临时文件写入权限失败，在获准的执行环境重试后，三端均导出成功。
- 安装依赖时 npm 报告 30 个依赖安全告警（4 moderate、25 high、1 critical）；本次未运行可能改变 SDK 依赖版本的 `npm audit fix --force`。未完成逐条归因与安全修复。
